# Shubh Sanjog Matrimony

A full-stack matrimonial web application demo built with Next.js (App Router), Tailwind CSS, TypeScript, and a Node.js/Express API with JWT-based auth, SQLite persistence, and demo admin/customer flows.

## Project Overview

This project includes:
- Public website UI for matrimonial marketing and lead generation
- OTP-based customer login and registration flow
- Customer dashboard with profile management
- Biodata builder for personal, education, family, and partner preference data
- Document and Kundli upload center
- Recommended matches with shortlist and interest actions
- Admin document verification queue with approve/reject workflow
- SQLite-backed persistence for users and profiles
- JWT-protected API routes

## Local Development Setup

### 1) Install dependencies

```bash
npm install
```

### 2) Start the backend (Express API)

```bash
node server/index.js
```

The backend runs on:
- http://localhost:4000

### 3) Start the frontend (Next.js)

```bash
npx next dev -H 0.0.0.0 -p 3000
```

The frontend runs on:
- http://localhost:3000

### 4) Seed demo data

A demo seed script is available in the project:

```bash
node server/scripts/seed-demo.js
```

This script creates:
- 1 admin user
- 5 customer profiles
- sample documents and notification data

## Main Routes

### Frontend
- `/` — Public home page
- `/login` — Login UI
- `/register` — Registration UI
- `/customer` — Customer dashboard
- `/customer/biodata` — Biodata builder
- `/customer/documents` — Documents and Kundli center
- `/customer/recommended` — Matches page
- `/admin` — Admin dashboard
- `/admin/documents` — Admin document verification page

### Backend API
- `GET /api/health`
- `POST /api/auth/send-otp`
- `POST /api/auth/verify-otp`
- `GET /api/profile`
- `POST /api/profile/personal`
- `POST /api/profile/education`
- `POST /api/profile/family`
- `POST /api/profile/preferences`
- `POST /api/documents/upload`

- `GET /api/documents/:id`
- `GET /api/dashboard/stats`
- `GET /api/matches/shortlist`
- `POST /api/matches/shortlist`
- `POST /api/matches/interest`
- `GET /api/notifications`
- `GET /api/admin/documents`
